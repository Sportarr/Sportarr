# Sportarr for Kodi

Kodi is the odd one out among Sportarr's media-server integrations: it needs
**no addon at all** to work correctly. Kodi reads local `.nfo` files and
poster/fanart images directly off disk, and Sportarr can write those for you
(Settings → Local Metadata in the Sportarr app). Turn that on, point a Kodi
TV Shows library at your sports folder, and you're done - see
[docs/integrations/kodi.md](https://wiki.sportarr.net) on the wiki.

This folder is for the **optional** second path: a real Kodi scraper addon
that looks events up dynamically against Sportarr's own metadata API
(`/api/metadata/agents/*` - the same routes the Plex/Jellyfin/Emby agents
call), instead of relying on files Sportarr already wrote. Install this only
if you specifically want Kodi to do its own live lookups.

## What's here

- `metadata.tvshows.sportarr/` - the scraper addon. Classic Kodi XML scraper
  contract (`CreateSearchUrl`/`GetSearchResults`/`GetDetails`/
  `GetEpisodeList`/`GetEpisodeDetails`), regex-extracting fields out of
  Sportarr's JSON API responses rather than scraping HTML.
- `repository.sportarr/` - a small repository addon so Kodi can install and
  auto-update the scraper from a URL, instead of a manual zip download every
  release.
- `repo/` - generated by `generate_repo.py`; served at
  `raw.githubusercontent.com/Sportarr/Sportarr/main/agents/kodi/repo/`, the
  same "static files in this repo, no separate hosting" trick the Jellyfin
  plugin's `manifest.json` already uses.

## Install

1. In Kodi, **Settings → File manager → Add source**, enter
   `https://raw.githubusercontent.com/Sportarr/Sportarr/main/agents/kodi/repo/`
   as the path, name it `Sportarr`.
2. **Add-ons → Install from zip file**, pick the source you just added, then
   `repository.sportarr/repository.sportarr-<version>.zip`.
3. **Add-ons → Install from repository → Sportarr Repository → Add-on
   metadata providers → Sportarr**.
4. Open the addon's settings and set **Server URL** (defaults to
   `https://sportarr.net`; point it at your own instance if you're
   self-hosting) and **Season year** (Sportarr's season numbers are the
   calendar year - keep this current, see the limitation below).
5. On a TV Shows library pointed at your sports folder, **Settings →
   Information provider → Sportarr**, then re-scan.

## Known limitation (v1)

The episode-list step only fetches the season matching the **Season year**
setting - it does not walk every historical season the way the local NFO
writer or the C# media-server agents do. If you need a full historical
back-catalog scraped, use the local metadata writer instead (no limitation
there), or update **Season year** and re-scan per season.

If something doesn't match up, open an issue with what Kodi's debug log
shows for the `metadata.tvshows.sportarr` scraper calls.
