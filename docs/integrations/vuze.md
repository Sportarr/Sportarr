# Vuze

Feature-rich torrent client with a Transmission-compatible remote interface.

| | |
|---|---|
| Protocol | Torrent |
| Default port | 9091 |
| Authentication | Remote username and password |

## Setup

1. Enable Vuze's remote web interface
2. In Sportarr, go to **Settings > Download Clients**, click **Add**, and choose **Vuze**
3. Enter the host, port, and credentials
4. Keep the category as `sportarr`
5. **Test**, then **Save**

Post-import modes, per-indexer client pinning, and remote path mappings are shared across all clients and documented under [Download Clients](../features/download-clients.md).
